# What's new in App Connect 2.1?

App Connect 2.1 is the next step forward for the product. Its headline change is support for both RingEX and RingCX, so knowledge workers and contact center agents can work from the same extension, against the same connectors, with the same logging and screen-pop behavior.

!!! info "This is the Frontier version of App Connect"
    The Frontier version is always the next version of App Connect. It's the latest and greatest, and it receives new features and updates on a weekly basis. Our primary version, by contrast, is optimized for stability and only receives bug fixes.

## Download the Frontier version

App Connect 2.1 is distributed as "App Connect 2.1" via an unlisted and private Chrome Store extension.
