  <div>
    <div class="crm-mkt__callout-title">What's a plugin?</div>
    <p class="crm-mkt__callout-desc">Unlike a connector, which integrates App Connect with an entire CRM, a plugin runs alongside an existing connector to change what happens around logging — before a log is saved, or in the background afterward. Admins install plugins from the App Connect admin console; developers can build one using the Plugin Server API.</p>
